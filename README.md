# OpenShift LLM Lab

This repository documents experiments, deployments and operational lessons learned while running LLM workloads on OpenShift and Kubernetes environments.

## Goal

The goal of this project is to explore what it really takes to run AI workloads in enterprise environments.

Most AI demonstrations focus on the model.

This lab focuses on everything around the model:

- OpenShift
- Kubernetes
- vLLM
- GPU operations
- Storage
- Networking
- Observability
- Reliability

## Why this matters

Running a model locally is easy.

Running AI reliably in production is a platform engineering challenge.

## Current Experiments

- vLLM deployment
- Qwen models
- PVC-backed model loading
- OpenShift Routes
- GPU validation
- Enterprise deployment patterns
